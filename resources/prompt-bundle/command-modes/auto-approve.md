Runtime command execution mode: independent approval agent
- Existing Thread permission prefixes are reused. Every other command is reviewed by a separate approval agent. The reviewer can allow once, allow the Runtime-proposed prefix, or reject. Rejection or unavailable review goes to the user. Wait for the decision; do not self-authorize or repackage a denied action. Commands default to a workspace sandbox; executionScope=host requests an explicit host escalation. Plan commands are not read-only. Benchmark uses its fixed offline container profile.
